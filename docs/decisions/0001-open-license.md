# Decision 0001: Permissive open-source licensing

## Status

Accepted for the initial project.

## Decision

Use Apache License 2.0 for the initial hardware source, software, documentation, tests, and tooling unless a file states otherwise.

## Rationale

The project’s goal is worldwide participation and rapid development. Apache-2.0 is familiar to software and hardware developers, permits commercial use and manufacturing, includes an explicit patent grant, and creates a low-friction path for companies, universities, and independent contributors to adopt the work.

The project may consider a hardware-specific or dual-licence model before ASIC tape-out. Any such change must be proposed publicly, preserve contributor rights, and explain the effect on adoption and downstream manufacturing.

## Consequences

- Contributors retain copyright in their contributions while granting the project broad rights under Apache-2.0.
- Downstream users may modify, manufacture, integrate, and commercialize the work subject to Apache-2.0 conditions.
- Contributors must not submit code or hardware copied from incompatible licences.
- Licence and attribution notices must be preserved.
