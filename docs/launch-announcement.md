# Launch announcement

## Short version

India needs its own AI inference chip. We are starting an open-source hardware and software project to build one in public.

The first milestone is a portable INT8 inference core. The long-term goal is an India-originated, globally developed path from open RTL and RISC-V software to FPGA prototypes and open ASIC silicon.

Developers from India and everywhere else are invited. Hardware, verification, FPGA, ASIC, compiler, firmware, benchmarks, documentation, and community contributions are all welcome.

Join the project: https://github.com/Vicky-RDP/india-inference-chip

## Suggested post

India needs its own AI inference chip—and we’re building the foundation in the open.

India Inference Chip is a global open-source project for AI inference hardware and software. We’re starting with a verified INT8 accelerator and will grow toward RISC-V integration, FPGA prototypes, compiler/runtime support, and eventually ASIC silicon.

Open source is the strategy: transparent designs, reproducible benchmarks, permissive Apache-2.0 licensing, and contributors from anywhere in the world.

If you work on chip design, RTL, verification, RISC-V, FPGA, ASIC, compilers, AI systems, or documentation, join us today:
