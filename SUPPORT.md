# Support

India Inference Chip is a community project. The fastest way to get help is to provide a reproducible question.

## Where to ask

- **How do I...?** Start a GitHub Discussion.
- **I found a reproducible defect.** Open a Bug Report.
- **I have an architectural idea.** Open a Hardware or Feature Proposal.
- **I found a security issue.** Follow [SECURITY.md](SECURITY.md).

## Include this context

- Operating system and tool versions
- Commit or branch name
- Exact command or test case
- Expected behavior
- Actual behavior and logs
- FPGA board or simulator, if relevant
